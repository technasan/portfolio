# Portfolio

Портфолио на двух языках (RU / EN): сайты под ключ, интернет-магазины, фронтенд-разработка.
Статический сайт без сборки.

## Структура

```
index.html            — страница (пока временная: список названий проектов)
content/site.json     — контент сайта: имя, контакты, языки, список проектов
projects/             — библиотека проектов, формат — в projects/README.md
  <папка>/project.json
  <папка>/*.jpg       — скриншоты
serve.ps1             — локальный сервер для просмотра
```

Проекты не зависят от сайта: папку проекта можно переносить между сайтами как есть.
Какие проекты показывать и в каком порядке — список `projects` в `content/site.json`.

## Языки

Любое текстовое поле в `site.json` и `project.json` — либо строка (одинакова для всех
языков), либо объект по языкам: `{ "ru": "Проекты", "en": "Projects" }`.

Сейчас язык выбирается параметром в адресе (`?lang=en`), по умолчанию — `defaultLanguage`.

## Локальный просмотр

Страницу нельзя открыть двойным кликом — браузер не даёт читать JSON с диска.
В папке проекта:

```
powershell -ExecutionPolicy Bypass -File serve.ps1
```

и открыть http://localhost:8000 (остановить — Ctrl+C). Другой порт: `-Port 8001`.
